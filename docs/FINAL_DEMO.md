# Final Demo Flow

1. Launch `./run.sh`.
2. Command Center: show dataset scale, graph edges and coverage.
3. Dataset Upload: select CSV/JSON/XML; show asynchronous ingestion status.
4. AI Analysis: show ROC-AUC, average precision and F1.
5. Alerts: sort/inspect high-risk transactions.
6. Investigation: drill into an alert and explain why it was prioritized.
7. 3D Graph: demonstrate the interactive graph surface.
8. Methodology: explain anomaly vs evidence and missing-field handling.

## Core judging message
The system is not a rules-only dashboard. It combines graph features,
supervised learning, unsupervised anomaly detection and explainable
prioritization, while supporting user-supplied datasets.
